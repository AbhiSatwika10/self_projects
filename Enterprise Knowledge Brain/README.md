# Enterprise Knowledge Brain (Agentic RAG)

AI-powered Enterprise Knowledge Assistant using:
- LangChain
- OpenAI
- ChromaDB
- FastAPI
- Streamlit
- Agentic RAG Architecture

## Features
- Upload PDFs
- Vector Embeddings
- AI Search
- Multi-Agent Workflow
- Enterprise Knowledge Retrieval
- Chat Interface
- Deployable to GitHub + Render/Vercel

## Run Locally

```bash
pip install -r requirements.txt
streamlit run frontend/app.py
```
