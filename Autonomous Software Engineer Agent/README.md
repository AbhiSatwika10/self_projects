# Autonomous Software Engineer Agent

An AI-powered autonomous coding agent inspired by Devin/Cognition-style systems.

## Features
- Multi-Agent AI Architecture
- Autonomous Task Planning
- Code Generation
- GitHub Repo Analysis
- Bug Fixing Agent
- Code Review Agent
- Terminal Command Executor
- RAG Memory
- Streamlit UI
- FastAPI Backend
- Docker Deployment

## Tech Stack
- Python
- FastAPI
- Streamlit
- LangGraph
- LangChain
- OpenAI
- ChromaDB
- GitPython

## Run

```bash
pip install -r requirements.txt

uvicorn backend.main:app --reload

streamlit run frontend/app.py
```
